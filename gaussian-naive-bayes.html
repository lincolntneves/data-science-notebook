How it learns

For each class, estimate its frequency and a bell curve for each input. Multiply the densities as if the inputs were independent given the class. The lab adds a small value to each variance and normalizes the two class scores. [1]

Equation and terms

s(c) = P(c) × ∏ Normal(xⱼ; μcⱼ, σ²cⱼ)

P(c) is the prior class frequency. Normal gives the density of input xⱼ around the class mean μcⱼ with variance σ²cⱼ. ∏ means multiply across inputs. If scores are 0.06 and 0.04, the first normalized score is 60%. [1] [2]

Lab

Use and evaluate

Useful as a quick baseline for continuous measurements. Correlated inputs can double-count evidence, so check calibration before treating scores as real-world probabilities. [2]

Review

Why does the model add a little variance?

An almost constant input can have variance near zero. The extra variance prevents a tiny spread from dominating the result.
