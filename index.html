Machine learning models

The models below learn from past examples. Some estimate a number, such as how much work a crew can finish. Others estimate a chance or choose a label, such as “on time” or “late.” Pick a model to start. Each lesson begins with an example and then explains how the model works.

Linear regression

How many square meters can a crew install in one shift? Rotate the 3D surface to see how the line is chosen.

Logistic regression

How likely is a delay? Move the threshold to decide when to flag a task.

Decision tree

Which questions lead to the prediction? Follow the path through the tree and compare the splits on the chart.

K-nearest neighbors (KNN)

Ask the most similar past cases to vote.

Gaussian naive Bayes

Combine a prior with evidence from each measurement.

Linear discriminant analysis (LDA)

Compare class centers using one shared description of spread.

Quadratic discriminant analysis (QDA)

Let each class have its own shape and orientation.

Linear support vector machine (SVM)

Find a dividing line with room on both sides.

Random forest

Pool predictions from many randomized trees.

Gradient boosting

Build a classifier one small correction at a time.

How to use the notebook

  1. Start with the lesson question and try to guess what the model would do.
  2. Select a colored symbol in the equation to see what it means.
  3. Change one control at a time and see how the equation values and chart respond.
  4. Try the review questions and follow the references for topics you want to explore.
