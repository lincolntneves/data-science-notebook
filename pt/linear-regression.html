Comece por aqui

Imagine colocar uma régua sobre pontos no papel. Cada ponto é um turno de trabalho que você já observou. No eixo horizontal ficam as horas, e no vertical, a área instalada. A reta resume a tendência para você estimar a área de um novo turno.

Treinar é usar exemplos anteriores, com resultado conhecido, para encontrar um padrão. Prever é aplicar esse padrão a um caso novo. O simulador usa dados fictícios para você observar o que muda ao mover um controle.

Exemplo passo a passo

Suponha que uma reta comece em 5 m² e suba 3 m² por hora. Para 4 horas, ela prevê 5 + 3 × 4 = 17 m². Se a equipe instalou 15 m², a diferença (real menos previsto) é −2 m². Essa diferença se chama resíduo.

O que vale lembrar

A inclinação descreve o padrão do exemplo. Para saber se trabalhar mais tempo causou a diferença, seria preciso avaliar outros fatores, como o tamanho da equipe e a dificuldade da tarefa.

A equação da reta, peça por peça

Imagine que você anotou quantas horas a equipe trabalhou e quantos m² instalou em vários turnos. Cada turno vira um ponto. A regressão linear ajusta uma reta para descrever a produção média esperada para uma dada duração. [1] [2]

ŷ = b₀ + b₁ × x
ŷ · previsão
Leia “y chapéu”. É o valor que a reta prevê, em m². Já y é o valor observado.
b₀ · intercepto
É onde a reta cruzaria o eixo vertical, quando x vale zero. Se zero fica fora dos dados, trate esse valor como uma peça da fórmula.
b₁ · inclinação
Quantos m² a previsão muda a cada hora a mais. Pode ser positiva, negativa ou zero.
x · entrada
A duração do turno, em horas. Em outro problema, a entrada poderia ser distância, temperatura ou outra medida.

Exemplo de cabeça. Se b₀ = 4 e b₁ = 5, para 6 horas temos 4 + 5 × 6 = 34 m². Em 7 horas, a previsão é 39 m². A hora extra mudou a previsão em 5 m².

Como o modelo escolhe a reta

Para medir o encaixe de uma reta candidata, calcule a diferença vertical entre o ponto observado e o valor previsto na mesma posição. Essa diferença é o resíduo. Se foram instalados 31 m² e a previsão era 34 m², o resíduo é −3 m². A reta previu 3 m² acima do observado. [2]

eᵢ = yᵢ − ŷᵢ

O índice i significa “esta linha da nossa tabela”. Elevamos cada resíduo ao quadrado para que erros positivos e negativos não se anulem e para que desvios grandes pesem mais. A soma se chama SSE. Dividindo pelo número n de exemplos, temos o MSE. Ambas escolhem a mesma reta para um conjunto de treino fixo. [2]

SSE = ∑ eᵢ² · MSE = SSE / n

∑ significa “some todos”. A superfície 3D mostra o MSE para várias inclinações e alturas da reta. Nela, a altura usada como parâmetro é a previsão na duração média dos turnos. A fórmula acima usa a previsão em zero horas como intercepto. As duas formas descrevem a mesma reta, usando pontos de referência diferentes.

Como calcular os coeficientes sem procurar reta por reta

A inclinação é a soma dos produtos (xᵢ − x̄)(yᵢ − ȳ) dividida pela soma de (xᵢ − x̄)². As barras indicam as médias de x e y. O intercepto é ȳ − b₁x̄, o que faz a reta passar pelo ponto das médias. A fórmula exige que haja variação nos valores de x. [2]

E se houver outras variáveis?

É possível acrescentar termos para equipe, tipo de parede e outras entradas. Na regressão múltipla, um coeficiente descreve a mudança na média prevista ao variar sua entrada e manter constantes as demais. A relação só tem interpretação causal quando o desenho da análise sustenta essa conclusão. [1]

Como usar e verificar

  1. Defina a previsão. Uma linha pode ser um turno. Registre os m² ao fim do turno e só use, na entrada, informações disponíveis no momento em que quer prever. Para planejar pela manhã, use horas planejadas se as durações reais ainda não forem conhecidas.
  2. Compare com uma referência simples. Use a média histórica como previsão inicial. Treine num período e teste em turnos posteriores quando a finalidade é prever produção futura. Use MAE para responder “quantos m² erro em média, em valor absoluto?” ou RMSE, que devolve a unidade m² e dá mais peso a erros grandes. [1]
  3. Examine os resíduos. Uma curva sugere que a forma linear pode faltar com parte do padrão. Um funil aponta para variação desigual. Turnos seguidos da mesma equipe podem ter erros dependentes. Normalidade é uma hipótese de certos procedimentos clássicos de inferência, não uma exigência para calcular a reta. [3] [4]
  4. Comunique a incerteza. Um intervalo de confiança para a média responde sobre a produção média esperada. Um intervalo de previsão responde sobre um turno específico e, sob as mesmas condições do modelo clássico, costuma ser mais largo. Evite projetar a reta para jornadas muito além das observadas. [4]

Revisão

Se o resíduo foi +7 m², a reta ficou acima ou abaixo do observado?

Abaixo. A produção observada superou a previsão em 7 m².

Por que adicionar o ponto extremo muda a previsão até para outros turnos?

O modelo recalcula uma única reta para todos os exemplos. O novo ponto influencia a inclinação e o intercepto, o que pode mudar as estimativas ao longo da reta.

Antes de rodar o código

Cole o exemplo completo de Python em um notebook Python ou salve em um arquivo .py e execute. Cole o exemplo de R no RStudio ou no console do R, ou salve em um arquivo .R e execute. Escolha uma das duas linguagens. Ambas usam os mesmos dados fictícios.

Os dados do exemplo

Cada linha representa um turno passado. hours é o número de horas trabalhadas e area é a área instalada em metros quadrados. Para o turno novo, você fornece só as horas. O objetivo é estimar a área.

Os resultados numéricos podem variar entre bibliotecas e em relação ao simulador da página. O código usa um conjunto pequeno de dados próprio para a prática.

Python

Python: instale a biblioteca uma vez no terminal.

python -m pip install pandas scikit-learn
import pandas as pd
from sklearn.linear_model import LinearRegression

# 1. Dados fictícios de tarefas anteriores
jobs = pd.DataFrame({
    "hours": [2, 3, 4, 5, 6, 8, 9, 10],
    "area": [9, 11, 15, 16, 21, 26, 28, 32],
})

# 2. Escolha as entradas e a resposta
X = jobs[["hours"]]
y = jobs["area"]

# 3. Ajuste ou prepare o modelo
model = LinearRegression()
model.fit(X, y)

# 4. Faça a previsão de um caso novo
new_job = pd.DataFrame({'hours': [7]})
print(model.predict(new_job).round(2))

Leia o código por etapas

  1. Importe as ferramentas As linhas de importação disponibilizam o modelo e o pandas. O pandas monta a tabela, chamada DataFrame. Um dicionário associa o nome de cada coluna à sua lista de valores. No histórico, todas as listas precisam ter o mesmo comprimento.
  2. Escolha as entradas e a resposta X contém só as colunas que o modelo pode ver. y guarda a resposta conhecida de cada linha do histórico. Os colchetes selecionam colunas pelo nome. X continua sendo uma tabela mesmo com uma única coluna de entrada.
  3. Ajuste o modelo fit(X, y) usa as entradas e as respostas passadas. Os valores ajustáveis escritos na chamada do modelo são configurações que você escolhe antes do ajuste. LinearRegression() cria um modelo que aprende uma reta. Com uma entrada, ele aprende o valor inicial e a mudança esperada na área a cada hora a mais.
  4. Faça a previsão para um caso novo new_job é uma tabela de uma linha com os mesmos nomes de entrada. predict usa o modelo ajustado. print mostra o resultado. Quando aparece [0], ele seleciona a primeira previsão, porque a tabela nova tem um caso só. round limita as casas decimais exibidas.

R

R: este exemplo usa funções que já vêm com o R. Nenhum pacote extra é necessário.

# 1. Dados fictícios de tarefas anteriores
jobs <- data.frame(
  hours = c(2, 3, 4, 5, 6, 8, 9, 10),
  area = c(9, 11, 15, 16, 21, 26, 28, 32)
)

# 2. Ajuste ou prepare o modelo
model <- lm(area ~ hours, data = jobs)

# 3. Faça a previsão de um caso novo
new_job <- data.frame(hours = 7)
print(round(predict(model, new_job), 2))

Leia o código por etapas

  1. Monte a tabela data.frame() monta a tabela e c() reúne os valores de cada coluna. A seta <- guarda o objeto com o nome à esquerda. Em uma expressão como jobs$late, o $ pega uma coluna pelo nome.
  2. Ajuste ou prepare o modelo Em uma fórmula, a resposta fica à esquerda de ~ e as entradas à direita. Um nome como MASS::lda usa a função lda do pacote MASS. Um fator guarda rótulos de classes. Algumas funções pedem explicitamente uma resposta numérica 0/1. lm() ajusta a reta. Leia area ~ hours como “explique a área a partir das horas”. A previsão sai em metros quadrados.
  3. Faça a previsão para um caso novo new_job é uma tabela de uma linha com os mesmos nomes de entrada do histórico. Em geral, predict recebe o modelo e essa nova tabela. Algumas funções, como knn, já fazem a previsão na mesma chamada. print exibe o resultado.
