How it learns

Start with the log-odds of the training delay rate. At each round, fit a one-split tree to yᵢ − pᵢ, the negative gradient of binary log loss. The lab computes a Newton update within each leaf, scales it by 0.25, and adds it to the current score. [1]

Equation and terms

Fₘ(x) = Fₘ₋₁(x) + η hₘ(x), p(x) = 1 / (1 + exp(−Fₘ(x)))

F is the running score on the log-odds scale, hₘ is the new tree correction, and η is the learning rate. The sigmoid maps the updated score to a probability. A score of zero gives 50%. [1] [2]

Use and evaluate

Boosting is useful for tabular patterns that one simple model misses. Tune the learning rate and number of trees together on validation data. Too many rounds can fit noise. [2]

Review

How does this differ from the random forest lab?

The forest averages trees fitted independently. Boosting fits the next tree using what the current ensemble gets wrong.
