Quadratic discriminant analysis (QDA)

Let each class have its own shape and orientation.

Start here

Imagine two clusters on a map. One is compact, while the other stretches along an avenue. A point far from the second cluster’s center can still fit that cluster along the avenue. QDA lets each group have its own shape, which can make the dividing line curve.

Training means using past examples with known outcomes to find a pattern. A prediction applies that pattern to a new case. The lab uses simulated data so you can see what changes when you move one control.

Example, step by step

Picture a point equally far from both centers. If the point lies along one group’s long axis but outside the other group’s compact area, the shapes give different evidence. The model weighs this together with how common each group was.

What to keep in mind

Giving each group its own shape asks more of the data. With very few examples in one group, its estimated shape can change sharply if you replace a single case.

How it learns

Like LDA, QDA models each class as Gaussian. It estimates a separate covariance for every class. The quadratic terms generally survive the comparison, which allows curved boundaries. [1]

Equation and terms

The math behind the idea

δc(x) = ln πc − ½ ln det(Σc) − ½ (x−μc)ᵀΣc⁻¹(x−μc)

μc locates the class, Σc describes its shape, and πc is the prior. The determinant reflects how spread out the class is. The final quadratic term measures distance from the center, accounting for the shape. [1] [2]

Try it in the lab

Move the white diamond near the boundary and compare small and large diagonal adjustments. Then open LDA and compare their boundaries. Ask which difference comes from estimating one shape per group instead of one common shape.

How to read the chart

The sliders place the white diamond on the chart. Move one slider at a time. The horizontal axis shows open items and the vertical axis shows delivery delay. The controls express both measurements on a 0–1 scale, with 0 meaning low and 1 meaning high. The colored background tells you which label the model would assign at that spot.

Lab

Use and evaluate

Try QDA when classes have different spreads and there are enough cases in each class. Compare with LDA on held-out data because separate covariance estimates can be noisy. [2]

Review

Why can QDA struggle when one class has very few examples?

It estimates a covariance for that class using just those examples, which can make the estimate unstable.
